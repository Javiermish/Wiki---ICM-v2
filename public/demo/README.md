# Archivos públicos de demostración

Contenido original creado exclusivamente para probar Wiki ICM, sin material académico de terceros ni datos personales. Dedicado a dominio público mediante **CC0 1.0**. No son evaluaciones oficiales ni representan la malla UdeC.

- `calculo-certamen-demo.pdf`: 3 páginas con texto seleccionable/buscable; Cálculo I, certamen 2, 2024-2, semestre curricular 1, sección 1, versión A.
- `calculo-listado-demo.png`: esquema original de una función.
- `calculo-apuntes-demo.webp` y `calculo-funciones-demo.jpg`: variantes del esquema para probar formatos.

Generación reproducible opcional: `python3 scripts/generate-demo.py` (Pillow). No necesaria para ejecutar/build; los binarios están incluidos.

Estos archivos son **públicos intencionalmente**, incluso por URL directa. No incorporar jamás aquí archivos pendientes, rechazados o privados. Desaprobar una ficha no revoca estos assets ni copias descargadas. El acceso definitivo se implementará en servidor y Storage privado; no se simula seguridad backend.
